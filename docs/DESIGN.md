# 设计方案：Neon Snake（全向霓虹贪吃蛇）

> 依据：`docs/RESEARCH.md` 的调研结论
> 日期：2026-09-14

---

## 1. 目标与非目标

**目标**：交付一个可直接静态部署、开箱即玩的单机全向贪吃蛇，视觉与手感对标 Slither.io 一档，玩法密度对标 Google Snake 的"多机制叠加"。

**非目标**：联机对战、账号系统、服务端排行榜、任何需要下载的外部美术/音频资源。

---

## 2. 技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 运行时 | 原生 ES Module，无打包器 | 与 Vercel "Other / 静态"预设天然契合；评审面小；无供应链风险 |
| 渲染 | Canvas 2D + 加性混合发光精灵 | 调研结论 §3.1：发光性价比最高 |
| UI | DOM + CSS（HUD、菜单、结算） | 文本锐利、可无障碍、可键盘操作；游戏世界才交给 canvas |
| 音效 | Web Audio API 程序化合成 | 零素材、零体积、零版权风险 |
| 测试 | Node 原生 `node:test` | 无依赖；纯逻辑模块（math/snake/collision/scoring/world）与 DOM 解耦，可直接被导入 |
| 持久化 | `localStorage`（带异常兜底） | 最高分、设置、成就、教学已读 |

## 4. 世界模型

### 4.1 坐标系与竞技场

- 世界为**圆形竞技场**，中心 `(0,0)`，安全半径 `R` 随时间从 `R0=1900` 线性收缩至 `Rmin=760`（`SHRINK_START=25s` 后开始，持续 `SHRINK_DURATION=180s`）。
- 头出圈即死亡；出圈前 220 单位进入"警戒区"，HUD 与小地图高亮预警。
- 采用圆形而非矩形：与全向移动语义一致，且让 AI 的边界回避容易实现。

### 4.2 蛇模型（`game/snake.js`）

- 状态：`x, y, angle, speed, targetTurn, mass, alive, boosting`。
- **路径采样**：每帧把头部位置压入路径折线；身体节点沿路径以固定弧长 `SEGMENT_SPACING` 反查得到——这是 Slither 一脉的标准做法，天然产生"跟随"手感且与帧率无关。
- 路径裁剪：保留总弧长 `= bodyLength + 2 * spacing` 的点，超出即丢弃，防止内存增长。
- 质量 → 半径 `r = R_BASE + R_GAIN * sqrt(mass)`；质量 → 速度 `v = V_BASE * (1 - CLAMP(mass * V_MASS_PENALTY))`（越大越慢，复刻 Slither 的大小制衡）。
- 转向：`angle` 以受限于 `TURN_RATE` 的速率向指令角收敛（`math.rotateTowards`），产生惯性感而非瞬转。
- 加速：`v *= BOOST_MULT`，同时按 `BOOST_MASS_COST` 每秒扣除质量；质量低于下限不可加速。
- 自碰豁免：头与**前 N 个节点**（`SELF_HIT_SKIP`，按弧长而非索引）不判定，避免贴颈误杀。

### 4.3 实体

| 实体 | 字段 | 说明 |
| --- | --- | --- |
| Food | `x, y, r, value, tier, phase, driftVx/Vy` | 三档：`common`(1) / `gold`(5) / `gem`(25)。`gem` 仅由蛇死亡爆出 |
| PowerUp | `x, y, type, ttl, phase` | `shield` / `magnet` / `slow` / `ghost` / `double` |
| Obstacle | `x, y, r, shape` | 静态陨石，接触即死 |
| Bot（即 Snake + AI） | 同 Snake，附加 `brain` | 3~6 条，随难度调整 |

### 4.4 碰撞（`game/collision.js`）

- 宽相：均匀网格 `cell = 96`，每步重建（本体节点数量有限，重建成本低于增量维护的复杂度）。
- 窄相：圆-圆距离判定。
- 判定优先级：出圈 → 障碍 → 其他蛇身 → 自身。
- 语义：**任意蛇的头撞到其他蛇的身体 → 头所在的蛇死亡**，其质量按 `DEATH_DROP_RATIO` 转化为 `gem` 食物环形爆开。

### 4.5 计分与连击

- `score += value * comboMultiplier`（`double` 道具再 ×2）。
- 连击：距上次进食 `< COMBO_WINDOW(2.6s)` 则 `combo++`，倍率 `= min(1 + floor(combo/3), 8)`；超时归零。
- HUD 显示连击槽倒计时环，倍率提升时播放升调音效与粒子。

### 4.6 缩圈与难度曲线

- `difficulty = EASY | NORMAL | HARD`，仅影响：AI 数量与 AI 反应延迟、初始速度、收缩速率、道具生成间隔。
- 不接受"后期无事可做"：缩圈 + AI 数量保证熵增。

## 5. 玩法规格（可验证）

| 编号 | 规格 |
| --- | --- |
| G-01 | 移动为连续全向，转向速率受上限约束，非格子跳变 |
| G-02 | 存在障碍物，撞上即死，死亡有明确视觉与音效反馈 |
| G-03 | 存在食物，吃掉后质量与分数增长、长度增加 |
| G-04 | 加速：速度提升且持续扣除质量，质量不足时禁用 |
| G-05 | 吃掉稀有食物获得更高分数 |
| G-06 | 连击：短时间连续进食提升倍率，超时重置 |

| G-08 | AI 蛇会追食物、避障、回避玩家、在有利时包夹玩家 |
| G-09 | 玩家撞 AI 蛇身 → 玩家死亡；AI 撞玩家身体 → AI 死亡并爆出食物 |
| G-10 | 死亡后结算界面给出本局统计与最高分对比 |
| G-11 | 竞技场随时间收缩，出圈死亡 |
| G-12 | 最高分持久化到 localStorage |
| G-13 | 成就系统：达成条件弹出提示并持久化 |
| G-14 | 三种主题可切换且立即生效 |
| G-15 | 支持暂停/继续/重开，切到后台自动暂停 |
| G-16 | 支持键盘、鼠标、触屏三套输入，移动端有独立加速按钮 |

## 6. 视觉规格

- **蛇身**：三层绘制 —— 加性发光底（低透明度宽描边）→ 主体渐变描边（圆头圆角连接）→ 高光内芯。头部有朝向性眼睛与周期性吐信。
- **发光**：统一使用预渲染径向渐变精灵 + `globalCompositeOperation='lighter'`，禁用在热路径使用 `shadowBlur`。
- **拖尾**：薄半透明覆盖叠加，非 `clearRect`。
- **粒子**：吃食迸射、加速尾焰、道具拾取环、死亡爆裂（按质量决定粒子数）、缩圈警示。
- **相机**：位置指数平滑跟随，朝向前瞻 `LOOK_AHEAD`；随质量增加缓慢拉远；事件驱动屏幕震动。
- **背景**：离屏缓存的星点 + 网格；运动视差；四周暗角。
- **HUD（DOM）**：分数、长度、连击环、道具计时条、小地图、AI 排行。
- **无障碍**：`prefers-reduced-motion` 降低震屏与粒子；全部交互元素可键盘 Tab 到达；对比度满足 WCAG AA。

## 7. 性能规格

- 固定时间步 `1/60s`，单帧最多 5 次追帧，避免死亡螺旋。
- 粒子池预分配，硬上限 `MAX_PARTICLES`（高/中/低画质 1400/700/220）。
- 自适应降级：连续 60 帧平均帧时 > 22ms → 降一档画质并提示。
- 页面隐藏时暂停循环；`resize` 防抖。
- 目标：中端笔记本 1080p 稳定 60FPS；iPhone 12 级别 55FPS+。

## 8. 测试计划

1. **单元测试（node:test）**：math 几何与角度归一化、rng 确定性、snake 路径采样与质量换长/半径/速度、collision 网格与判定、scoring 连击倍率边界、world 缩圈与出圈判定、ai 决策在给定情形下的输出。
2. **静态检查**：全部模块语法与导入解析（Node 直接 import）。
3. **无头浏览器冒烟**：加载页面 → 无 console error → 开始游戏 → 模拟输入 N 秒 → 断言游戏状态推进与 canvas 有非空像素 → 截图人工复核。
4. **边界与异常**：极窄窗口、DPR=1/2/3、`localStorage` 被禁用、音频被浏览器策略拦截、长时间运行无内存增长（路径裁剪验证）。

## 9. 交付与部署

## 10. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 全向移动 + 自碰撞易"贴颈误杀" | 弧长豁免区 + 转向速率上限 |
| 后期蛇极长导致渲染掉帧 | 节点数上限；超出时增加采样间距（视觉无损） |
| AI 与障碍/边界卡死 | AI 决策包含边界与障碍前视探针；卡死超时强制转向 |
| 无构建步骤下模块路径错误导致白屏 | 全部相对路径 + 冒烟测试拦截 |
