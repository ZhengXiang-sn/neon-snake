玩法说明

移动

鼠标移动 / 手指拖动 → 蛇头朝该点转向；A / D 或 ← / → → 相对左右转。转向有惯性，不是瞬转。

加速冲刺

按住左键或 Shift / 空格加速，速度 ×1.6，但每秒持续消耗质量；质量见底会自动松开。触屏双击并按住，或按住右下角「加速」。

身体是武器

任何蛇的头撞到别的蛇身即死，并爆出一地宝石。以小吃大靠的是走位，不是体型。

连击

2.6 秒内连续进食累积连击，每 3 层提升一级倍率，最高 ×8。

道具

缩圈

25 秒后竞技场开始收缩，出圈即死。边缘泛红时要立刻往中心走。
